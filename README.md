⚡ Workflow Friction Monitor

Every Delay Tells a Story. Every Insight Drives Improvement.

Workflow Friction Monitor is a web-based workflow analytics application designed to identify bottlenecks, analyze process efficiency, and highlight areas for improvement. It helps transform workflow data into meaningful visual insights for better decision-making.

🚀 Project Overview

In many organizations, delays and inefficiencies occur at different stages of a workflow. Identifying where these problems happen can be challenging.

Workflow Friction Monitor addresses this challenge by analyzing workflow stages, measuring friction levels, and presenting performance information through an interactive dashboard.

✨ Key Features

- 📊 Performance Dashboard — Monitor workflow statistics and performance indicators.
- 🔍 Friction Analysis — Identify stages with high friction and potential delays.
- 📈 Visual Analytics — Understand workflow performance through charts and visual representations.
- 🚦 Friction Classification — Categorize workflow stages into low, medium, and high friction levels.
- 💡 Actionable Insights — Highlight potential opportunities to improve workflow efficiency.

🔄 How It Works

1. Collect: Obtain workflow stage information and performance data.
2. Process: Analyze the available data to calculate or assess friction levels.
3. Identify: Highlight stages that may cause bottlenecks or delays.
4. Visualize: Present workflow performance through a dashboard.
5. Improve: Use the insights to identify opportunities for process optimization.

🎯 Problem Statement

Organizations often lack a clear view of where their workflows experience delays, inefficiencies, or bottlenecks. Without this visibility, improving operational performance becomes difficult.

💡 Proposed Solution

Workflow Friction Monitor provides a centralized interface to analyze workflow stages, visualize friction levels, and identify areas that may require improvement.

⚙️ Getting Started

Prerequisites

- Node.js and npm
- Python
- Git

Installation

1. Clone the repository

git clone https://github.com/KEERTHI1826/Friction_Monitor_React_FastAPI.git

2. Navigate to the project folder

cd Friction_Monitor_React_FastAPI

3. Install frontend dependencies

Navigate to the directory containing the frontend "package.json" file and run:

npm install

4. Start the frontend

npm run dev

5. Run the backend

Install the Python dependencies listed in the backend's requirements file, then start the FastAPI application using the entry point configured in your project.

Refer to the actual frontend and backend folder structure for the correct commands.
